# Emotion Detector

An AI-powered emotion detection web application developed
using Python, IBM Watson NLP, and Flask.

## Features
- Detects anger, disgust, fear, joy, and sadness
- Identifies the dominant emotion
- Provides a web interface using Flask
- Handles invalid or empty input
- Includes five unit tests
- Passes Pylint static code analysis

## Technologies
- Python
- IBM Watson NLP
- Flask
- Requests
- unittest
